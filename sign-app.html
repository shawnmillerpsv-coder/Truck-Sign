Presets

Panel layout

Drag a panel to move it. Drop it on another panel to swap. Numbers = order on the data wire. Each row of panels is one line.

Preview

Preview font is close to the sign's but not pixel-exact. Phone numbers are exact.

Big scene (whole sign)

When the message wraps around, everything pauses and the scene plays across all panels for about 4½ seconds.

Animations between words

Tap in a line's text where it should go, then pick one. Example: WHOLESALE {$} LOWEST PRICES

Color single letters

Tap in a line's text where the color should start, then Insert. Example: HALF PRICE{FF0000}!{}
